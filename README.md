# SKYLARK (Windows 版)

ESP32 のデモ `TFT-Tester-XEV/src/skylark.cpp` を、Windows で人が操作して遊べる縦シューティングにしたもの。
イギリスの片田舎の上をプロペラ機で飛び、ときどき来る円盤を落とし、さらわれそうな羊を助ける。

`SkyLark.exe` をダブルクリックで起動する。インストールは要らない (Windows に入っている .NET Framework 4 で動く)。

## 画面

- 絵は 320x540 の点で描き、2 倍して **640x1080** で出す。
- 画面の高さが 1080 の PC では、タイトルバーとタスクバーのぶん窓が入りきらないので、縦横比を保って縮めて出す。
  **F11 (または Alt+Enter) で全画面にすると、ちょうど 2 倍の 640x1080** で真ん中に出る。
- 窓の大きさは自由に変えられる (縦横比は保ち、余りは黒)。
- ゲームは 1 秒 30 回進めるが、描くのは 1 秒 60 回。動くもののあいだを補って描くので、景色や自機がなめらかに動く。

| ゆっくり動く | Shift | LB / LT |

| 一時停止 | Esc / P | START |
| 止めているときにタイトルへ戻る | Q | BACK |
| 全画面 ⇔ 窓 | F11 / Alt+Enter | |
| 表示の切り替え (真上 ⇔ 2.5D) | F2 | |
| 音を消す ⇔ 出す | M | |

ネームエントリー: 上下で文字を選び、Space (パッドは A) で次の文字へ、Backspace (パッドは B) で戻る。キーボードで名前を直接打って Enter でもよい。

ほかの窓に移ると、自動で一時停止する。

## 2.5D 表示 (F2 で切り替え)

F2 を押すと、いつもの真上からの表示と、**飛び出す絵本のような 2.5D 表示**が切り替わる (選んだ表示は次に起動したときも続く)。遊び方と当たり判定は同じ。

- 地面はいつもの絵を奥へ傾けて映す。カメラで撮ったような遠近法で、まっすぐな畦や川はまっすぐのまま奥へすぼまる。空は画面の上の少しだけで、画面の上の端よりさらに奥 (約 20 マス先) の畑や村、近づいてくる名所まで見える。遠くはもやに溶ける。画面の上には空と、紙を重ねた遠い丘、お日さま (夕方は沈み、夕暮れには月)、紙の雲。
- 羊・牛・犬・家・木・教会・パブ・納屋・汽車・ストーンヘンジ・ネッシーなどは、白いふちと厚紙の切り口のある**紙の張りぼて**。家や教会は正面から見た絵。奥から流れてくると、寝ていた張りぼてがパタンと起き上がる。
- 自機はうしろの少し上から見た形 (横に広がる主翼、手前の尾翼) で、機首の前でプロペラが透けた円盤のように回る。
- 地面と張りぼては、となりあう点の色を混ぜて映すので、斜めにしたり拡大縮小したりしても点のギザギザが目立ちにくい。
- 自機・円盤・母船・弾は少し高いところを飛び、地面に影を落とす。円盤は横から少し見下ろした厚みのある形 (上の面、ガラスのドーム、灯りの並ぶ縁、光る底)。
- 見本は samples/25D_sample.png、同じ場面のいつもの表示との比較は samples/A_vs_25D.png。

## 物語「ひばり号と羊どろぼうの円盤」

ある春の朝、ウィルトシャーの谷に円盤がやってきた。ねらいはイギリスの羊の毛。村の郵便飛行機乗りは、古いプロペラ機「スカイラーク (ひばり) 号」で円盤を追い払うが、母船は逃げるたびに別の地方へ移り、行く先々で羊をねらう。スカイラーク号は円盤を追って、イギリスの田舎を旅する。

- 1 日ごとに地方が変わる。日の始まりに**旅の絵はがき** (地方の名前と絵、短い便り)、日の終わりに**イギリスの地図**の上をスカイラーク号が次の地方へ飛ぶ場面が出る (どちらも撃つボタンで先へ進める)。
- 予定は 5 日: DAY 1 ウィルトシャー → DAY 2 湖水地方 → DAY 3 ヨークシャー → DAY 4 コーンウォール → DAY 5 スコットランド高地。最後は宇宙人が手編みのセーターをもらって帰っていく。
- いまできているのは DAY 1 と DAY 2。それまでは DAY 1 と DAY 2 をくり返す (DAY 3 はウィルトシャー)。

| 日 | 地方 | 景色 | 名所・UMA | 天気 |
|---|---|---|---|---|
| DAY 1 | ウィルトシャー | 生け垣のパッチワークの畑、村、パブ | ミステリーサークル、ストーンヘンジ (ボドミンの野獣とネッシーも、DAY 4・5 ができるまではここ) | にわか雨 |
| DAY 2 | 湖水地方 | 石垣の牧草地、点々とある湖とボートやヨット、灰色のハードウィック羊、野うさぎ、白い壁にスレート屋根の家、さび色のシダの山 | キャッスルリッグの石の環、湖の怪物ボウネッシー | 長い霧雨のあとに虹 |

## ゲームの流れ

- 何も押さずにいると、元のデモ (自動操縦) が 1 周流れる。タイトル → 遊ぶ様子 → ランキング。いつでも START で始められる。
- 1 日 約 3 分: **AREA 1** 牧草地の谷 → にわか雨 → **AREA 2** 山と湖 → 夕焼け → **母船** → 夕暮れ → THE VALLEY IS SAFE。
- 1 日を終えると **次の日** へ (地形も天気も新しく、朝から)。点・残機・弾の強さは持ちこす。
  2 日目からは、円盤の弾が速く、偵察機が多く、母船が硬くなる (DAY 6 ぐらいで上限)。
- 自機は 3 機 (画面左下の飛行機の印は残りの数)。4 万点と、そのあと 10 万点ごとに 1 機ふえる。
- 3 機の輪を全部落とすと **P** (弾が 2 → 4 → 5 本に。最大のときは 2000 点)。やられると 1 段下がる。
- 円盤が羊や牛を光線で持ち上げているあいだに落とすと **SAVED** (1000 点、1 日の終わりにも 1 匹 1000 点)。
- 母船は 30000 点。落とすと煙を引いて墜落し、地面に残骸が残る。
- 助けた羊 (牛) は、ハートを浮かべてぴょんぴょん跳ねながら群れに戻る。間に合わずに連れ去られると「BAA...」(牛は「MOO...」) と、遠ざかる声が残る。

## のどかな景色

- 牧草地の羊には、ときどき牧羊犬 (ボーダー・コリー) がついていて、群れのまわりを走りまわる。犬が近づくと羊は逃げる。ときどきワンと吠える。
- 家の横に洗濯物が干してあり、風に揺れる。
- 川をカモの親子が一列で泳いで渡り、向こう岸に上がるとよちよち歩く。ときどきクワッと鳴く。
- 村のはずれにパブがある (白壁に黒い梁、羊の絵の看板)。夕焼けが深まるとほかの家より先に灯りがともり、看板のランプが前の道を照らす。
- 山あいにも、ときどき小さな集落ができる。

## 名所

- **ストーンヘンジ** (毎日 76 秒ごろ、雨が上がったあと): 生け垣も畑もない白亜の草原が広がり、真ん中に立つ。ほかと違って斜め上から見下ろした形で描き、立った石が重なって見え、影が右下の草に落ちる。石は本物より数を減らして (外の環は 16 本) 太く大きくしてある。
  まわりの土手と堀、北東へ延びるアヴェニューとヒールストーン、まぐさ石を載せた石の環 (ところどころ欠けている)、内側の 5 組の三石塔とブルーストーン。
- **ネッシー** (毎日 106 秒ごろ、AREA 2 の山あい): 大きな湖 (ロッホ) があらわれ、ネッシーが湖をゆっくり回りながら、首を出したり沈んだりする。あの有名な写真のように横から見た茶色のシルエット (すっと立つ長い首、うつむいた小さな頭、うしろに低いこぶ) で、水面に揺れる映り込みと波紋がつく。水から出るときはザバッと音がする。
- **ミステリーサークル** (毎日 30 秒ごろ、朝の谷): 生け垣で囲まれた大きな麦畑があらわれ、高いところを飛ぶ小さな円盤が、光を落としながらぐるりと回って麦を倒し、模様 (真ん中の渦、外の輪、3 つの小さな円) を描きあげて飛び去る。この円盤は高いところの飾りで、撃っても当たらない。
- **ボドミンの野獣** (毎日 96 秒ごろ、AREA 2): コーンウォールの荒れ地に出るという大きな黒い山猫。画面の端から駆けてきて、途中で座り、金色の目でこちらを見て低くうなり、また走り去る。近くの羊は逃げまどう。
- 名所からは円盤が湧いてくる。ストーンヘンジは真ん中が緑に光り、小さな円盤が大きくなりながら地面から浮かびあがる (ふしぎな音)。湖では水の下に黒い影があらわれ、水しぶきの輪を広げて浮上し、しずくを落とす。出きるまでは撃っても当たらず、ぶつかってもやられない。出きると偵察機と同じように蛇行しながら降りてくる。
- 真上を飛ぶと「見つけた」ボーナス: ミステリーサークルとストーンヘンジは 3000 点、ボドミンの野獣は 4000 点、ネッシーは水から出ているときだけ 5000 点 (1 日 1 回ずつ)。竪琴のような音が鳴る。
- 残機がなくなると **CONTINUE?** (10 秒)。撃つボタンで続けられる。続けると点のいちばん下の桁がコンティニューの回数になる。
- やめると GAME OVER。5 位以内ならネームエントリー。

## 音

素材ファイルは使わず、すべてその場で合成している (`Sound.cs`)。
プロペラのうなり、機銃、爆発、円盤のうなりと光線、母船、雨、雷、汽笛、羊の声、小鳥のさえずり、短い節。
デモのあいだは半分の音量。
プロペラの音程は自機の動きで変わる: 前へ出ると上がり、うしろへ下がると下がり、横へ旋回すると少し上ずって、うなりが揺れる。

## 設定とランキング

`%APPDATA%\SkyLark\` に、1 つにつき小さなテキストファイル 1 つ。

| ファイル | 中身 |
|---|---|
| `scores.txt` | ランキング 5 行 (`点 名前`) |
| `name.txt` | 前回入れた名前 (次のネームエントリーの最初の文字) |
| `view.txt` | 表示 (25 = 2.5D) |
| `window.txt` | 窓の位置と大きさ、全画面だったか |
| `sound.txt` | 音量と、音を消しているか |

読めない・壊れているときは既定で動く。保存した位置が画面の外になっていたら、既定の位置に出す。

## 作り

| ファイル | 中身 |
|---|---|
| `Game.cs` | ゲームの中身 (地形、円盤、母船、自機、天気、遊びの流れ)。ESP32 版の `skylark.cpp` をほぼそのまま移した |
| `GameDraw.cs` | 描くところ。ESP32 版の `draw()` と同じ順で重ねる |
| `GameDraw25.cs` | 2.5D 表示 (F2)。地面を奥へ傾けて映し、羊や家を紙の張りぼてとして立てる |
| `GameDrawB.cs` | 案 B (絵本風) の試作。見本の画像を書き出すだけ |
| `GameStory.cs` | 物語と地方: 旅の絵はがき、地図の場面、地方ごとの天気や羊、湖水地方のもの (ボート、うさぎ、キャッスルリッグ、ボウネッシー、虹) |
| `Gfx.cs` | 点の絵を描く道具。LovyanGFX と同じ描き方 (円や楕円の点の並びも同じ)、6x8 の文字、文字で描いた点の絵 (`Sprite`)、影 (下の色を暗くする) |
| `Sound.cs` | 音の合成と、winmm の waveOut に流すところ |
| `Program.cs` | 窓、1 秒 30 回の進行、キーボードとゲームパッド、設定の保存 |

- 1 秒 30 回進める (ESP32 版と同じ速さ・同じ時刻表)。描くのが遅れたときは進めるだけ先にする。
- ゲームの中身 (`Game.cs`) は 213x360 の世界で動く (ESP32 版の 170x320 を広げたもの。地面は 22 → 27 列)。
  当たり判定・速さ・時刻表は ESP32 版のまま。
- 描くとき (`GameDraw.cs`) だけ 1.5 倍して 320x540 の点で描く。地面の 1 マスは 12 点で、作物の畝や花、生け垣の葉、石垣の石、
  水辺の岸、岩肌の凹凸まで点ごとに描く。地面は行ごとに描き置き、新しい行ができたときだけ描く。
  羊・牛・飛行機は文字で描いた点の絵、家・教会・木・円盤・母船は点ごとに光を計算して描く。
  置き物・飛ぶもの・雲は、地面に半透明の影を落とす。
- 色掛け (`tint`) は 24 ビットの色で計算する。
- 描くところを `GameDraw.cs` にまとめてあるので、いずれ絵の作りを丸ごと変える (なめらかなイラスト風にする等) ときも、ゲームの中身は触らずに済む。
- 地面は画面の上の端より 21 行ぶん奥まで前もって作る (2.5D で遠くまで見えるように)。そのぶん地形を作るのを先回りさせて、名所などが画面に入ってくる時刻は前と同じにしてある。汽車は線路が画面の上の端まで来てから走りだし、カモとミステリーサークルも画面の上の端まで来てから動きだす。
- 1 秒 60 コマ: 動くものはみな前のフレームの位置 (`ox, oy`) を覚えていて、描くときに前と今のあいだを補った位置 (`rx, ry`) で描く。
  大きく飛んだとき (出てきた、上へ回りこんだ) は補わない。止めているあいだやコンティニューを待つあいだは補わない。
- `GameDrawB.cs` は案 B (イラスト風) の試作。いまは見本の画像を書き出すだけ (System.Drawing のなめらかな描画)。
- ESP32 版のソースは触っていない (別の複製)。

## ビルド

```
build.bat
```

Windows に入っている `csc.exe` (.NET Framework 4) でビルドする。SDK は要らない。
最初の 1 回だけ、できた exe 自身に `SkyLark.ico` (ゲームの飛行機の絵) を作らせてから、アイコン入りでビルドしなおす。

### 確かめる用のオプション

窓を出さずに進めて、指定したフレームの絵を PNG (2 倍 = 640x1080) に書き出す。

```
SkyLark.exe --snap      <出力の頭> <フレーム>...   デモを流す
SkyLark.exe --snap-play <出力の頭> <フレーム>...   START を押して何もしない (やられてコンティニュー → GAME OVER → 名前)
SkyLark.exe --snap-god  <出力の頭> <フレーム>...   やられない自機で撃ちながら左右に動く (次の日への切り替えを見る)
SkyLark.exe --wav <ファイル>                        効果音を全部 WAV に並べ、音ごとの最大の振れ幅を出す
SkyLark.exe --bench                                 デモを 1 周、毎フレーム描いて、描くのにかかった時間を出す
SkyLark.exe --census    <何でも> <最後のフレーム>     デモを流し、1 秒ごとに画面にいる牧羊犬・カモ・パブ・洗濯物・跳ねる羊・光線の数を出す
SkyLark.exe --sample-b  <出力の頭> <フレーム>...    A の絵と、同じ場面の案 B (イラスト風) の見本を書き出す
SkyLark.exe --bench-b                               案 B の描き方で 1 枚描くのにかかる時間を出す
```

環境変数 `SKYLARK_VIEW` を 25 にすると 2.5D の絵で書き出す (--bench も同じ)。環境変数 `SKYLARK_SEED` に数を入れておくと、乱数の種がそれに決まり、何度流しても同じ場面になる (見本や確認に使う)。

## これからの案

- **イラスト風 (案 B)**: 見本は `samples/B_sample.png`、同じ場面の A との比較は `samples/A_vs_B.png`。
  利用者の感想は「ドット絵 (A) のほうがゲームっぽい」(2026-10-26)。B は保留。
  速さ: いまの描き方 (System.Drawing) では 1 枚 平均 218ms、最悪 333ms (Core i5-13400)。1 秒 60 コマ (1 枚 16.7ms) には 13 倍ほど足りない。
  ゲームにするなら、絵を描くのをグラフィックボードに任せる仕組み (WPF か Direct2D) に作りかえる必要がある。
- 済んだこと (2026-10-26): 1 秒 60 コマ、跳ねて群れに戻る羊、連れ去られるときの声、牧羊犬、洗濯物、カモの親子、パブの看板、ストーンヘンジ、ネッシー、名所から湧く円盤、操作で変わるプロペラの音、ミステリーサークル、ボドミンの野獣。
- 気に入られているところ (崩さない): のどかな田園の雰囲気、羊が円盤にさらわれそうになる場面。
